# Diner menu PDFs

Drop the menu PDFs in this folder using these exact filenames — the "View
the Menu (PDF)" buttons on the Diner pages already link to them, so no code
changes are needed once the files land here:

- `diner-fargo-menu.pdf` — Marge's Diner, Fargo
- `diner-ottertail-menu.pdf` — Marge's Diner, Ottertail

The Supper Club menu is unaffected — it keeps pulling live from the Team
Portal (Firestore), not a static PDF.
